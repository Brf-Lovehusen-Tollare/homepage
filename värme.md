Lägenheterna försörjs med uppvärmning, ventilation och tappvarmvatten genom lägenhetsseparata
frånluftsvärmepumpar. Värmepumpen utvinner energi ur den frånluft som annars blåses rakt ut.

Den nuvarande installerade Comfortzone värmepumpen behöver inte veckovis tillsyn, men var 3:e månad bör filter rengöras, och var 12:e månad bör filter bytas. Nya filter kan köpas direkt från ComfortZone på sin webbsida [https://shop.comfortzone.se/en/products/luftfilter-rx](https://shop.comfortzone.se/en/products/luftfilter-rx)

Styrelsen har på senare tid fått frågor angående luftvärmepannans kvartalsvisa indikation gällande dess luftfilter. Indikationen är lite trubbig såtillvida att den inte skiljer på byte resp rengöring av luftfiltret. Istället anger den vid varje tillfälle att filtret ska bytas. Luftfiltret ska bytas årligen. Däremellan ska luftvärmepannans meddelande om filterbyte förstås som att filtret ska rengöras. Som framgår i ComfortZones manual skickar systemet en påminnelse om byte/rengöring var 90:e dag.

[Bruksanvisning för ComfortZone RX50 Frånluftsvärmepump](https://www.brflovehusentollare.se/assets/skötselråd/ComfortZone RX.pdf){: .btn }

Värmen distribueras genom vattenburen golvvärme. Golvvärme är ett trögt system där det kan vara
lite fördröjning vid häftiga temperaturomslag ute. I små rum med begränsad golvyta kan det vara
olämpligt med stora tjocka mattor som gör att värmen inte sprids jämnt i rummet.

Lägenheten får tilluft via ventiler i fönster. Dessa ventiler ska hållas öppna. Om inte rubbas balansen så att vissa rum kan bli utan friskluft.
